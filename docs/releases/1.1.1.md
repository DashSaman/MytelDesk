# MytelDesk 1.1.1

The first backend activation now allows up to 900 seconds for a cold Node.js
startup and database initialization on slow storage. It returns as soon as the
backend reports healthy with an active AMI connection, and continues to show
elapsed readiness notices while waiting.

Ready-install upgrades retain their 300-second activation budget. Normal doctor
checks, same-release checks and rollback budgets are unchanged. A failed first
activation still restores its configuration transaction and retains prepared
data, accounts and secrets for reviewed recovery.

This patch changes installer timing only. Application, telephony, audio, VAD,
database schema and dependency sources are unchanged from 1.1.0. Automated tests
exercise delayed readiness, immediate readiness, the 900-second failure bound
and preservation during rollback. Live-host verification is recorded with the
release notes on GitHub.
