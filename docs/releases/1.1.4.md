# MytelDesk 1.1.4

When Asterisk records HANGUP JSON in CEL, Desk uses its cause, dial status
and source channel to enrich the call outcome and identify who ended the
call. Desk reads the vendor `eventextra` column when the standard `extra`
payload is unavailable, preserving metadata recorded before an upgrade.
When neither payload carries usable details, Call History uses CDR data.

This Desk release makes no changes to the PBX database schema. Capture of
details for future calls depends on the PBX's CEL writer configuration.
