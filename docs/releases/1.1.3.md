# MytelDesk 1.1.3

Native Issabel SIP rows can declare `flags` as `INT NOT NULL` without a default.
MytelDesk now supplies `flags=0` when inserting a SIP keyword, including the
secret retirement performed when deleting an application user. Duplicate-key
updates and updates to existing rows preserve their current flags.

The equivalent missing-row path used for native WebRTC settings also supplies
`flags=0`. This patch changes no database schema or dependency versions.

Six regression cases exercise the strict native schema, existing flags,
idempotent updates and database error propagation. Live lab retirement
acceptance is recorded separately from the automated checks.
